A short passage written for the pause between one verdict and the next. Rain on a tin roof in a nameless village, light still travelling from a star that set out before any verdict existed — the piece asks nothing of its reader and lets the quiet do the work.

## Run it

```sh
node main.ts
```

This writes the passage to `/output/entry.txt`.
